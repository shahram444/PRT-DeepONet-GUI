# Code of conduct

This is a small scientific project. The expectations are the ordinary ones.

Be civil. Disagree with the work rather than with the person. Assume the other
person is trying to get it right, because usually they are.

Say what you measured. A claim that something is broken carries more weight
with the command that showed it than without.

Take correction the same way you give it. Being wrong in public about a
numerical result is the normal cost of doing this kind of work, and nobody here
is keeping score.

Harassment, personal abuse, and any conduct that would be out of place in a
university department are not acceptable, in issues, in pull requests, or in
private messages arising from either.
